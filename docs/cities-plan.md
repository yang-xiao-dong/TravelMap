# 城市专题推进计划（31 省 92 城全覆盖）

城市专题以**城市建成区与近郊**为单位组织机位（天际线夜色 / 古城街区 / 江河湖海界面 / 市井烟火 / 周边一小时圈），与省区专题（全域）、国道专题（走廊）互为补充。

## 覆盖规则

- 31 个省级行政区，**每省至少 3 城**；直辖市为单城。
- **省会/首府 + 15 个副省级城市优先**（沈阳、大连、长春、哈尔滨、南京、杭州、宁波、厦门、济南、青岛、武汉、广州、深圳、成都、西安）。
- 全量清单见 `data/cities/manifest.json`（`capital`/`subpro` 标记）；总览图 `maps/cities-map.html`。

## 上线流程（每批）

1. 写 `data/cities/<pinyin>.json`（与省区数据同构；`pinyin` 字段用 `city-<拼音>` 防止与省页重名；城市类数据加 `cat_extra` 的 `night` 城市夜景分类；不需要 `route` 字段）。
2. `python tools/gen_theme_map.py data/cities/<pinyin>.json` → 生成 `maps/city-<pinyin>-map.html`。
3. `python tools/build_cities_index.py` → 刷新 `data/cities.js`（上线状态自动判定）。
4. `index.html` 城市区块追加已上线城市卡片、更新「已上线 N/92」计数。

## 数据口径备忘

- 城市页坐标系与全站一致：WGS84 近似参考点，导航以实地为准。
- 夜景/天际线类点位用 `night` 分类（#364fc7）；古城街区人文仍用 `culture`。
- 与省区页/国道页重复的地标（如中山桥、黄果树）允许跨专题出现，撰写角度按专题分工差异化：城市页侧重「机位+时段+城市动线」，省区页侧重全区位，公路页侧重走廊串联。
