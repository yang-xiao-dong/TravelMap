# 城市专题数据撰写规范（供分批撰写用）

目标：为 `data/cities/<pinyin>.json` 撰写与首批 9 城（昆明/大理/丽江/兰州/敦煌/张掖/太原/大同/运城）同构、同质量的城市采风数据。

**必读范例**：`data/cities/kunming.json`（结构最全）、`data/cities/lanzhou.json`、`data/cities/dali.json`。撰写前先通读。

## 选题立场

城市专题以**城市建成区与近郊**为单位组织机位：天际线夜色、古城街区、江河湖海界面、市井烟火、周边一小时圈（最远可到 ~100km 的标志性地物，如昆明的石林）。与省区页侧重全区位不同，城市页侧重「机位+时段+城市动线」。每城 6–8 个景区（省会/副省级/旅游重镇取 8，一般地级市取 6–7），共 12–18 个机位。

## JSON 结构（逐字段）

```json
{
  "pinyin": "city-<拼音>",            // 文件名是 <拼音>.json，此字段带 city- 前缀
  "title": "<城市> · 城市采风",
  "h1": "<城市> · 城市采风",
  "em": "<8字内城市定位短语>",          // 门户卡片副题，如「省会 · 春城」「苍洱之间」
  "accent": "#<hex>",                 // 城市性格主色，同批内不重复
  "subhead": "城市机位 → 景区 → 街区 三级结构 · %(n)d 景区 %(m)d 机位",  // %(n)d %(m)d 占位必须保留
  "center": [lat, lon],               // 城市中心（用下发坐标）
  "min_zoom": 7,                      // 近郊点很远时可用 6
  "z_init": 12,
  "cal_title": "季节日历",
  "calendar": ["<b>月份段</b> 一句何时何地拍什么怎么拍", ...],   // 7 条：花期/候鸟/节庆/夜拍/天气窗口/通透度等
  "route_name": "<城市>",
  "region_order": ["<片区A>", "<片区B>", ...],   // 3-5 个，城市地理分区，如 古城片区/滨江/城市街巷/近郊
  "cat_extra": { "night": { "label": "城市夜景·天际线", "color": "#364fc7" } },
  "lodging": [{ "n": "…", "lon": …, "lat": …, "type": "…", "tip": "…" }],   // 1 条，机位导向的住宿建议
  "local": [{ "n": "…", "type": "…", "region": "…", "month": "…", "tip": "…", "lon": …, "lat": … }, ...],  // 4 条美食/风物/夜市
  "spots": [ … ]
}
```

### spot 结构

```json
{
  "id": 1,
  "name": "景区名（可含·并置）",
  "region": "<region_order 中的关键词>（区县/方位）",   // region 必须包含 region_order 某项作为子串，分组靠它
  "lon": …, "lat": …,                 // WGS84 近似即可（小数 3 位），导航以实地为准
  "cat": "culture",                    // 主分类
  "themes": ["culture", "night"],      // 题材标签，与 cat 同池
  "win": "拍摄窗口：季节+时段+光线",     // 如「11–3月晨光顺光；全年夜景 19:30 后」
  "note": "实操提醒：人流/门票/交通/报备",  // 1 句
  "story": "2-3 句人文掌故，要有年代、人物或数字，写出『为什么值得拍』",
  "subs": [
    { "n": "机位名", "lon": …, "lat": …, "yaw": 200, "tip": "构图+参数级要点：焦段/快门/时机" },
    { … }   // 每景区 2-3 个机位
  ]
}
```

### 分类池（cat/themes 只能取这些）

`bloom` 花海 · `fall` 瀑布溪流 · `leaf` 红叶秋色 · `cloud` 云海日出星空 · `lake` 峡谷水体地质 · `bird` 冬季候鸟 · `culture` 人文史迹同框 · `night` 城市夜景天际线（cat_extra 提供）。城市页大量使用 `culture` 与 `night`，滨水用 `lake`，候鸟湿地用 `bird`，花事用 `bloom`。

## 质量红线

1. **机位 tip 必须是摄影语言**：焦段（24mm 广角/200mm 长焦压缩）、快门（1/2000s 连拍/30s 车轨）、光线（逆光剪影/蓝调时刻）、构图（前景引导线/对角线/倒影），不要写成旅游攻略。
2. **story 必须有信息量**：年代、人名、数字至少占其二。禁止「历史悠久的著名景点」这类空话。
3. **坐标合理**：景区坐标相对城市中心的方向距离要对（故宫在天安门北 500m，不是随便偏 2km）。机位坐标在景区坐标 ±0.01° 内微调。
4. **每城至少 1 个 night 类**（天际线/江岸夜色/灯光地标），至少 1 个近郊 escape。
5. **人视模拟依赖真实地形**：山城/江城/海岸的机位 yaw 要符合朝向（江北拍南岸 = 朝南 yaw≈180）。
6. 每个文件写完立刻跑 `python tools/validate_data.py data/cities/<pinyin>.json`，必须 ALL OK。
7. UTF-8 无 BOM，中文标点，JSON 用 2 空格缩进，与范例文件一致。

## 完成后

批次内全部城市写完并 ALL OK 后，对每个文件跑：
`python tools/gen_theme_map.py data/cities/<pinyin>.json`
确认输出 `maps/city-<pinyin>-map.html`。
